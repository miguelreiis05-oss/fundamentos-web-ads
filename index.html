Bem-vindo(a)!

Esta é a página inicial do meu projeto prático da disciplina de Desenvolvimento Front-End Para Web. Ela foi construída utilizando apenas os elementos de HTML básico vistos em aula até o momento: títulos, parágrafos, listas, tabelas, links e imagens.

O objetivo desta atividade não é a estilização (isso vem mais adiante, com CSS), mas sim praticar HTML e, principalmente, o versionamento de código com Git.
